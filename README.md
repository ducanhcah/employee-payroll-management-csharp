# Quản lý nhân viên C#

Ứng dụng console quản lý nhân viên toàn thời gian và nhân viên thời vụ.

## Chức năng

- Nhập và hiển thị danh sách nhân viên.
- Tính thâm niên, phụ cấp, thực lĩnh và tổng quỹ lương.
- Tìm nhân viên, tính tiền thưởng và xóa nhân viên theo mức thực lĩnh.

## Công nghệ

- C#
- .NET 10
- Lập trình hướng đối tượng

## Cách chạy

Từ thư mục dự án, chạy lệnh:

```powershell
dotnet run --project .\NguyenDucAnh_3324\NguyenDucAnh_3324\NguyenDucAnh_3324.csproj
```
